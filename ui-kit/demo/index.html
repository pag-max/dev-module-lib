配色方案（分类数据 2 / 3 / 4 元）

铁律：① 图表/色块对比度 ≥ 3:1，文字 ≥ 4.5:1（WCAG）；② 分类数据单图最佳 ≤ 4 类；③ 浅底 / 深底各一套（同一色在两套背景对比度会反转）；④ 色不能单独表意——必配图标或文字。 下方每个色都实时计算在浅/深底的对比度，标红即 <3:1，该背景下请换同色相变体或加 1px 描边 + 文字冗余。
